# slither-io

An offline single-player version of the slither client. There's no server: the game runs locally against 30 AI snakes.

Open `index.html` in a browser to play.

## Controls

- Mouse: steer
- Hold mouse button, Space or Up arrow: boost
- Left and Right arrows: turn
- Enter: play

## Layout

- `index.html`: page markup
- `css/style.css`: page styles
- `js/game.js`: game client and the offline world (AI, food, prey, collisions, leaderboard, minimap)
- `img/ui/`: menu buttons
- `img/skins/`: skin decals
- `img/backgrounds/`: background textures
